# Lockdown Studios public-site visual system

This is the shared design base for the live site. Home, Services and Websites set the pattern; individual subjects change the content, not the page grammar.

## Page grammar

1. Header and navigation: one shared component, with a clear current section and one primary project CTA.
2. Hero: small numbered or descriptive eyebrow, one concise headline, explanatory paragraph, primary action and secondary jump. A split illustration, product preview, playable demo or image-led artwork occupies the other column when relevant.
3. Detail: numbered rows for scope, process or key facts. Alternate translucent dark-teal sections so stars remain visible without sacrificing contrast.
4. Proof: image-led project cards, concept demos or a real interactive element. Label concepts and work in progress honestly.
5. Pricing: three comparable cards for priced offers, as on Websites. Scope-priced work gets one prominent custom-quote card with cost factors and an enquiry CTA. No invented fixed package price.
6. Closing: one compact CTA band, then one compact footer. Avoid repeating large contact panels on subpages; the full enquiry form remains on Home.

## Visual rules

- Dark charcoal and teal are the shared background and accent. Service identity comes from artwork and copy rather than an entirely different page palette.
- Match hero, heading, section spacing and card scale across public pages. Use the Games-style text-over-art treatment for game projects where artwork is the strongest visual.
- Buttons may glow subtly on hover/focus. Keep text contrast and visible keyboard focus. Respect reduced-motion preference.
- Illustrative artwork and fictional website demos must be labelled. Do not present them as client outcomes.

## Review order

Home → Services → Websites → Apps → Games & Interactive → 3D & Animation → AI & Automation → Projects → project detail pages → About → privacy/utility pages. The three fictional before/after examples intentionally retain different industry-specific designs because comparison is their purpose; the surrounding studio pages use this system.
